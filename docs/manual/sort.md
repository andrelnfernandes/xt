# Sort

Alt+S sorts the files by **N**ame, **E**xt, **D**ate or **S**ize. **O**rder
toggles ascending and descending, and **P**ath first groups the files by
directory in Branch and Showall (both keep the menu open, so you can choose the
key next).

The current order appears in the file window's title (`Size↓`) and the cursor
stays on the same file. Each window has its own order; the initial one comes
from `sort` and `sort_descending` in the [configuration](configuration.md), and
new windows (F8, Log) inherit the current one.
