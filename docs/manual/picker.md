# Picking a folder (F2)

In any prompt that asks for a folder ([Copy and Move](copy-move.md),
[Log](treespec.md), and the folder of [Batch](execute.md) and of
[archive creation](archives.md)), **F2** opens a tree to choose it, as in
ZTreeWin.

It starts at the folder typed so far; the tree keys move around (directories
are read as they are opened), **Tab** switches to the other window's tree with
the screen [split](split.md), **Enter** puts the folder in the prompt (Batch
and archive creation keep the file name) and **Esc** goes back without changing
it. Nothing runs until you confirm the prompt.
