# 比较

在 [分屏](split.md) 状态下，在目录树中按 `C` 会将当前目录的文件与另一窗口目录中的文件进行比较，并根据您的选择标记符合条件的文件：

- **U**nique（独有）：另一侧不存在的文件；
- **N**ewer（更新）与 **O**lder（更旧）；
- **I**dentical（相同）：大小与日期均相同；
- **D**ifferent（不同）；
- **A**ll new（全部新内容）：独有 + 更新，即要使另一侧保持最新所缺少的文件。

按 **B**（或在目录树中按 Alt+C，与 ZTreeWin 一致）会将比较范围切换为整个分支：Xylem 会载入该分支，按相对路径（`src/a.rs` ↔ `<另一窗口>/src/a.rs`）进行比较，并打开显示已标记文件的 Branch 视图。

相差不超过 2 秒的日期视为相同（FAT 与 exFAT 以 2 秒为单位记录时间）；`compare_ignore_1h` 还会忽略恰好相差 1 小时的时间差（夏令时）。这两项设置均位于 [配置](configuration.md) 的第 4 页。

同步目录的方法：依次按 `C` `B` `A`，然后按 Alt+C（[保留路径复制](copy-move.md)），此时会自动建议将另一窗口作为目标目录。
