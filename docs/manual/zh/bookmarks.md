# 书签

书签可以让您用单个按键（`0`–`9`、`a`–`z`）快速跳回常用的目录。书签会随提示行历史记录一起在多次运行之间保存。

- **Ctrl+F11**（或在目录树中按 Ctrl+B）保存当前目录：接着按下要分配给它的按键即可。
- **`'`** 跳转到书签：按下书签对应的按键。在同一提示行中，再按一次 `'` 或按 Enter 会打开书签列表，按 `+` 则保存当前目录。
- **F11**（或 Alt+B）打开书签管理器：↑ ↓ 选择，Enter（或书签对应的按键）跳转，Del 删除，Insert 或 `+` 保存当前目录，Esc 关闭。

不在当前目录树内的书签目录会作为新的目录树打开，效果与 [Log](treespec.md) 相同。在文件窗口中，Ctrl+B 是 [批处理](execute.md)，因此在那里请使用 Ctrl+F11 保存书签。
