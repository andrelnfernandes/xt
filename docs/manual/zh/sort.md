# 排序

Alt+S 可按 **N**ame（名称）、**E**xt（扩展名）、**D**ate（日期）或 **S**ize（大小）对文件排序。**O**rder 切换升序与降序，**P**ath 则在 Branch 和 Showall 中先按目录对文件分组（这两个选项都会保持菜单打开，方便您紧接着选择排序字段）。

当前的排序方式会显示在文件窗口标题栏中（如 `Size↓`），且排序后光标仍停留在同一文件上。每个窗口都有各自的排序顺序；初始顺序由 [配置](configuration.md) 中的 `sort` 和 `sort_descending` 决定，新窗口（F8、Log）会继承当前的排序顺序。
