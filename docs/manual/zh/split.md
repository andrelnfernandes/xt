# 分屏

**F8** 打开第二个窗口（初始位于同一目录），再次按 F8 恢复为单窗口。**Tab** 在两个窗口之间切换（未分屏时，Tab 的作用与 Enter 相同）。每个窗口都有各自独立的目录树、光标、[Filespec](filespec.md) 和 [排序顺序](sort.md)；使用 `L`（[Log](treespec.md)）可在其中打开另一个目录。

在分屏状态下：

- [复制与移动](copy-move.md) 会默认建议将另一窗口的目录作为目标路径；
- [比较](compare.md) 会与另一窗口进行比较；
- 在 [文件夹选择器](picker.md)（F2）中，Tab 可切换到另一窗口的目录树；
- 任何操作完成后，两个窗口都会自动刷新。
