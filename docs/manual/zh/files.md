# 文件窗口

文件窗口列出目录树光标所在目录中的文件，或整个分支（`B`），或所有已载入目录（`S`）中的文件。**Enter** 返回目录树，**Esc** 也会返回（并定位到所选文件所在的目录）。

## 移动光标

| 按键 | 功能 |
|---|---|
| ↑ ↓ PgUp PgDn Home End | 移动光标 |
| ← → | 向上 / 向下翻页（在多列模式下：上一个 / 下一个文件） |
| Backspace | 显示父目录的文件 |
| Shift+字母、0–9 | 跳到以此开头的下一个文件 |
| Space | 下移一行 |

## 显示模式 (Alt+F)

Alt+F 按 ZTreeWin 的顺序循环切换：**多列名称**、**多列名称与大小**、**详细信息**（单列显示大小、日期与权限，默认模式）和 **长名称**（单列，仅显示完整名称）。

在切换到长名称之前，还有两种 ZTreeWin 没有的模式：

- **所有者 (owner)**：显示大小、`用户:组` 和权限（在 Windows 或归档文件内部不显示）；
- **类型 (type)**：根据可见文件开头的字节判断每个文件的类型，类似 `file` 命令（如 "PNG image, 800 x 600"、"ELF 64-bit executable"、"python3 script"、"Rust, UTF-8 text" 等）。

在多列模式下，文件从左到右排列，← → 移动一个文件，↑ ↓ 移动一行；超过 20 个字符的名称会以 `…` 截断。初始模式由 [配置](configuration.md) 中的 `file_display` 指定。

## 自动预览 Autoview (F7)

将屏幕分为文件列表与所选文件的内容两部分，预览内容随光标移动。文件窗口的按键依然有效（例如按 `T` 标记）；Shift+↑ ↓ PgUp PgDn Home End 滚动文件内容；`W` 切换软换行，`#` 切换行号；F7、Esc 或 Enter 退出预览。它显示每个文件的前 1 MiB（`V` 最多显示 16 MiB）。

## 打开文件

- `V`：[查看器](viewer.md)（文本或十六进制，支持搜索）。
- `E`：编辑器（[编辑](execute.md)）。
- `O`：在后台使用系统默认程序打开（`xdg-open`：用看图软件打开图片，用阅读器打开 PDF 等）。Ctrl+O 打开所有已标记的文件。在归档文件内部，条目会先解压到临时文件夹，并在 Xylem 退出时删除。可在 `opener` 中设置其他程序。
- Alt+F5：将 [归档文件](archives.md) 作为目录打开。

## 隐藏的方向控制字符

某些不可见字符会改变文本的书写方向，因此文件名看起来可能与实际不同（Trojan Source，CVE-2021-42574；例如 `fatura\u{202E}fdp.sh` 可能看起来像一个无害的 PDF）。Xylem 绝不会把它们发送到终端：它们在文件名中以红色标出，光标位于这类文件名上时页脚会提示 "Name has hidden bidirectional characters"，按 `O` 打开前会要求确认，并把这些字符以 `\u{XXXX}` 的形式写出来显示。

## 剪贴板

`Y` 或 Ctrl+Insert 将文件路径（在目录树中则是目录路径）复制到剪贴板；Ctrl+Y 复制所有已标记文件的路径，每行一个；查看器中的 `y` 复制正在查看的文件路径。它支持通过 SSH 和 tmux（OSC 52）工作，并且在 X11 和 Wayland 下退出 Xylem 后剪贴板内容依然保留。

## 其他命令

| 按键 | 功能 |
|---|---|
| `T` / `U` | 标记 / 取消标记文件并下移（[标记](tagging.md)） |
| `C` / `M` | [复制 / 移动](copy-move.md) 文件 |
| `D` 或 Del | [删除](delete.md) 文件（Shift+Del：永久删除） |
| `R` | [重命名](rename.md) 文件；Ctrl+R 使用掩码批量重命名已标记文件 |
| `A` | [权限](attributes.md) |
| `N` | [修改日期](attributes.md) |
| Alt+S | [排序](sort.md) |
| Ctrl+S / Ctrl+V | [搜索已标记文件 / 查看它们](search.md) |
| Ctrl+B | [批处理](execute.md)：为每个已标记文件生成一行脚本 |
| F5 / Ctrl+F5 | 用当前文件 / 已标记文件创建 [归档文件](archives.md) |
| Alt+I | Info：文件详情（[信息](info.md)） |

另请参阅：[目录树窗口](tree.md)、[当前生效的按键](keys.md)。
