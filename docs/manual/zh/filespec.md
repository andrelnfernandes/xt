# Filespec：文件过滤器

`F` 设置在文件窗口中显示哪些文件（每个窗口都有各自独立的过滤器）。当前的 filespec 会显示在窗口标题栏中。过滤条件以空格、`;` 或 `,` 分隔，共有三种类型，与 ZTreeWin 一致：

- **名称：** 通配符模式（如 `*.rs`、`a?c*`、`[abc]*`），不区分大小写；用引号括住的名称可以包含空格（如 `"my file*"`）；
- **日期：** `<`、`=`、`>`、`<=`、`>=` 或 `<>` 后跟符合当前配置格式顺序的日期，分隔符可用 `/`、`.` 或 `-`，年份可为 2 位或 4 位（如 `>01/05/2026`；`2026-05-01` 始终有效），或者使用 `TODAY` 和 `TODAY-n`（如 `>TODAY-7` 表示最近 7 天）；
- **大小：** 在运算符后加 `s`（如 `>=s200000`）；也支持 `K`、`M` 和 `G` 单位（如 `>s100M`）。

前导 `-` 表示取反（如 `-*.bak`；`-<s1K` 等同于 `>=s1K`）。在同一类型内部，正向条件之间为“或 (OR)”关系，但紧接着 `<b` 的 `>a` 例外，它表示两者之间的范围（如 `>=01/05/2026,<=31/05/2026` 表示五月）；`<>` 表示排除。不同类型之间为“与 (AND)”关系：`*.txt,=TODAY,<s1000` 表示今天修改且小于 1000 字节的 `.txt` 文件。

`*`（或直接留空）显示所有文件。按 **↑** 调出之前用过的 filespec。
