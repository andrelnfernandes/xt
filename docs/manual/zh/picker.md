# 选择文件夹 (F2)

在任何要求输入文件夹的提示行中（[复制与移动](copy-move.md)、[Log](treespec.md)，以及 [批处理](execute.md) 和 [创建归档文件](archives.md) 的文件夹），按 **F2** 都会打开目录树供您选择，就像在 ZTreeWin 中一样。

目录树会从目前已输入的文件夹开始定位；使用目录树按键移动光标（目录会在打开时读取），在 [分屏](split.md) 状态下按 **Tab** 可切换到另一窗口的目录树，按 **Enter** 将所选文件夹填入提示行（批处理与创建归档文件会保留原文件名），按 **Esc** 返回且不作修改。在您最终确认提示行之前，不会执行任何操作。
