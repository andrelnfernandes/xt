# 筛选行

在查看器的文本模式下，`&` 只显示匹配的行。这些行只是被隐藏，内容不会改变：打开行号（`#`）后，每一行都保留它在文件中的行号，行号的间隔可以直观地显示筛选的效果。标题栏会显示结果：`[filter error: 24 of 850 lines]`。

| 提示符中的按键 | 作用 |
|---|---|
| **F1** | 本帮助 |
| **F2** | 区分或忽略大小写 |
| **F3** | 反选：保留不匹配的行 |
| **F4** | 纯文本或正则表达式 |
| ↑ ↓ | 之前的筛选条件 |
| Enter | 应用 |
| Esc | 取消 |

## 正则表达式

除非使用锚点，否则表达式可以匹配行中的任何位置。除非按 **F2**，否则忽略大小写；这里重音会被区分。

| 写法 | 匹配 |
|---|---|
| `.` | 任意字符 |
| `\d` `\D` | 数字，非数字 |
| `\w` `\W` | 字母、数字或 `_`，其他字符 |
| `\s` `\S` | 空白，非空白 |
| `[abc]` `[^abc]` | 其中之一，除这些之外 |
| `[a-z0-9]` | 这些范围内的一个字符 |
| `^` `$` | 行首，行尾 |
| `\b` | 单词边界 |
| `a*` `a+` `a?` | 零个或多个，一个或多个，零个或一个 |
| `a{3}` `a{2,5}` | 正好 3 个，2 到 5 个 |
| `a+?` | 一个或多个，尽可能少 |
| `(abc)` | 分组，用于重复或多选 |
| `(?P<name>abc)` | 命名分组 |
| `(?i)` `(?-i)` | 从此处起忽略或区分大小写 |

竖线分隔多个选项：`error|fail|fatal`，或在分组内写 `disk (full|error)`。

要匹配特殊字符 `. * + ? ( ) [ ] { } ^ $ \` 或竖线本身，请在前面加 `\`：`\.log$`、`\(1\)`。

## 示例

- `^\d{4}-\d{2}-\d{2}`：以日期开头的行
- `\b(error|fatal)\b`：这些完整的单词，不分大小写
- `^\s*$` 配合 **F3**：隐藏空行
- `^\s*#` 配合 **F3**：隐藏 shell 脚本中的注释
- ` 50\d `：访问日志中 500 到 509 的 HTTP 错误
- `\b\d{1,3}(\.\d{1,3}){3}\b`：含有 IPv4 地址的行
- `(?-i)TODO`：只匹配大写，即使忽略大小写

这里特意不支持反向引用（`\1`）和环视（`(?=...)`）：没有它们，耗时只随文本大小增长，任何文件或表达式都无法用 `(a+)+$` 这样的模式让查看器卡住。

## 纯文本

规则与搜索相同：忽略大小写时，重音也不计（`AÇÃO` 能找到 `ação`），中间的 `*` 匹配同一行内的任意内容（`error*disk`）。

## 筛选开启时

再次按 `&` 可以修改筛选条件。**在空提示符上按 Enter 会关闭筛选**，屏幕顶部的那一行保持不动。如果筛选条件没有匹配任何内容或无效，则不会有任何改变，页脚会说明原因。

筛选开启时，滚动和[搜索](viewer.md)只经过保留的行。`g` 接受文件中的行号；如果该行被隐藏，则跳到下一个保留的行。编辑文件（`E`）或更改编码（`O`）后筛选仍然有效，关闭查看器时结束。

只有查看器读取的内容才会被筛选：如果标题栏显示 `(showing first N MiB)`，文件的其余部分不会被检查。筛选看到的是显示出来的行，因此制表符是空格（请使用 `\s`，而不是 `\t`），控制字符是 `·`。在表格模式下，`&` 打开 SQL 筛选。

另请参阅：[查看器](viewer.md)。
