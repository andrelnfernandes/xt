# 删除、回收站与 Prune

## 删除 (Delete)

`D` 或 Del 删除光标下的文件（在目录树中则是删除目录，仅限空目录）；Ctrl+D 删除已标记的文件。Xylem 在删除前始终会先询问。

如果在 [配置](configuration.md) 中设置了 `delete_to_trash = true`，文件和空目录会被移入系统回收站（Linux 上为 FreeDesktop Trash，Windows 上为回收站），而不是直接移除。在确认提示时，无论配置如何，按 **T** 都会移入回收站，按 **P** 则永久删除。**Shift+Del** 始终直接永久删除。

## 撤销删除 (Oops)

**Oops**（在目录树中按 `O`，或在任一窗口中按 Ctrl+Z）可将上一次移入回收站的内容恢复到原位。若本次会话尚未将任何内容移入回收站，它会提议恢复系统回收站中最近的项目。

## 修剪目录树 Prune（在目录树中按 Alt+P）

删除目录及其中的所有内容。Xylem 会先载入整个分支，显示将被删除的文件数、目录数和字节数，并要求您 **输入 PRUNE**（或目录名称，或 Y，具体取决于 `prune_confirmation` 设置）。它会从最深层开始向上依次删除文件和目录，期间显示进度，按 `Esc` 可取消。符号链接会被直接移除而不会追踪其目标，且 **分支内部挂载的其他挂载点会被跳过**（挂载在其中的 U 盘不会被删除）。目录树的根目录不能被 Prune。Prune 始终是永久删除。
