# 搜索已标记的文件

## Ctrl+S

在当前列表的所有已标记文件中搜索文本，并 **取消标记不包含该文本的文件**，期间显示进度，按 `Esc` 可停止。在提示行中，按 **F2** 切换是否区分大小写（忽略大小写时也会忽略重音符号，如 `AÇÃO` 可匹配 `ação`），按 **F4** 在文本与十六进制（如 `4d 5a` 这样的字节对）之间切换。搜索词中间的 `*` 可匹配同一行内的任意内容（如 `error*disk`）；匹配绝不会跨越换行符。此功能在 [归档文件](archives.md) 内部同样有效。

## Ctrl+V

在 [查看器](viewer.md) 中逐个打开已标记的文件：**N**ext 和 **P**rev 切换文件（Alt+Home 和 Alt+End 跳到第一个和最后一个），**U** 取消标记当前文件。搜索词与 Ctrl+S 共享：执行 Ctrl+S 后，在 Ctrl+V 中按 **Space** 会直接跳到下一个匹配处，当到达文件末尾时会自动跳到下一个已标记的文件。

常用操作流程：标记文件（按 `T`，或在 Branch 中按 Ctrl+T），按 Ctrl+S 搜索关键词，按 Ctrl+V 打开查看器，然后按 Space 依次浏览所有文件中的匹配项。
