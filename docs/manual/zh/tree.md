# 目录树窗口

目录树显示已载入（读取到内存）的目录。下方的文件窗口列出光标所在目录中的文件。

## 移动光标

| 按键 | 功能 |
|---|---|
| ↑ ↓ PgUp PgDn Home End | 移动光标 |
| → 或 `+` | 展开目录 |
| ← 或 `-` | 折叠目录（或转到父目录） |
| Backspace | 转到父目录 |
| Space | 下移一行 |
| Shift+字母、0–9 | 跳到以此开头的下一个目录 |
| `\` 或 `/` | [Treespec](treespec.md)：输入路径跳转到指定目录 |
| Enter 或 Tab | 进入文件窗口（在 [分屏](split.md) 下 Tab 用于切换窗口） |

在目录树中，连接线上的 `+`（`├─+`）表示含有子目录且当前处于折叠状态的目录。

## 载入目录 (Logging)

目录会在打开时读取。`*` 会载入并展开光标下的整个分支；若载入时间较长，底部会显示进度，按 `Esc` 可取消。**F3**（或 F2）从磁盘重新读取目录。Xylem 还会监控每个窗口的当前目录，当其他程序修改该目录时自动重新读取（在任何正在进行的操作完成后，最多每半秒一次）；其他目录仍需按 F3 刷新。

`L`（[Log](treespec.md)）在窗口中打开另一个目录。

## 文件列表

- `B` (Branch)：显示整个分支的文件（会先载入该分支）。
- `S` (Showall)：显示所有已载入目录中的文件。
- `F` ([Filespec](filespec.md))：按名称、日期与大小过滤要显示的文件。

在 Branch 与 Showall 视图中，按 `\` 可跳转到所选文件所在的目录。

## 目录树中的命令

| 按键 | 功能 |
|---|---|
| `T` / `U` / `I` | 标记 / 取消标记 / 反选该目录中的文件（[标记](tagging.md)） |
| `M` | 新建子目录 |
| `R` | 重命名目录 |
| `D` 或 Del | 删除目录（仅限空目录，见 [删除](delete.md)） |
| Alt+P | Prune：删除目录及其中的所有内容 |
| `O` 或 Ctrl+Z | Oops：恢复刚移入回收站的内容 |
| `N` | 修改目录日期（[日期](attributes.md)） |
| `C` / Alt+C | 与另一窗口 [比较](compare.md) 当前目录 / 整个分支 |
| `A` | Avail：已挂载的文件系统（[信息](info.md)） |
| Alt+I | Info：目录详情 |
| Alt+K | 在每个目录旁显示大小、文件数或百分比 |
| `Y` | 将目录路径复制到剪贴板 |
| `X` | [执行](execute.md) shell 命令 |
| Alt+X | 打开 [内置终端](terminal.md) |
| F8 | [分屏](split.md) |
| F11 / Alt+B | [书签](bookmarks.md)；Ctrl+B 保存书签 |

另请参阅：[文件窗口](files.md)、[当前生效的按键](keys.md)。
