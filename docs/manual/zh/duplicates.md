# 重复文件 (Alt+Y)

查找内容相同的文件(无论名称和文件夹如何),以及副本浪费的空间。**Alt+Y** 在当前目录的分支中查找;在磁盘用量视图中按 **D** 则在所列文件夹中查找。

释放空间最多的排在最前。除非您要求,否则不会标记任何内容,并且每组始终保留一个副本:Xylem 不允许标记最后一个。

## 选择要移除的内容

| 按键 | 作用 |
|---|---|
| ↑ ↓ PgUp PgDn Home End | 移动 |
| `T` 或空格 | 标记或取消标记该副本 |
| `K` | 保留此副本:标记同组其他副本 |
| `A` | 在每组中标记除一个以外的全部;再按 `A` 更改保留哪一个:最旧、最新、路径最短 |
| `F` | 在每个有副本位于此副本所在文件夹的组中,保留那一个 |
| `U` | 取消全部标记 |
| `D`、Del 或 Ctrl+D | 删除已标记的,与 Delete 命令相同 |
| `M` 或 Ctrl+M | 移动已标记的文件 |
| `G` | 文件或整个文件夹 |
| `V` 或 Enter | 查看文件 |
| `E` | 将列表写入文件(绝不覆盖已有文件) |
| `\` | 关闭视图,目录树定位到该文件夹 |
| F3 | 重新读取文件夹并再次比较 |
| Esc 或 Alt+Y | 关闭 |

删除或移动之前,会再次检查每一组:如果某个副本在分析后发生了变化,或者本应保留的副本已不存在,则不会触碰该组的任何内容。

## 整个文件夹

**G** 显示内容完全相同的文件夹:相同的名称、每个文件相同的内容以及相同的链接。如果文件夹中有未比较的内容(无法读取的文件夹、挂载在其中的其他磁盘、特殊文件或被忽略的文件夹),它绝不会被视为副本。

## 如何比较文件

只读取大小与其他文件相同的文件:先读两端,再分段读中间,使用 SHA-256。比较在后台进行,Esc 可取消。以下内容不在列表中:小于 `duplicates_min_size`(默认 1 KiB)的文件、空文件、链接、同一文件的其他硬链接、其他磁盘,以及 `duplicates_ignore` 中的文件夹(`.git` 和 `node_modules`)。

在网络文件夹中,会先询问要读取的总量。在远程机器上或压缩包内暂不可用。

## 云端 (rclone)

在 `rclone mount` 挂载的文件夹中,Xylem 向 rclone 获取服务已保存的哈希值(`rclone lsjson --hash`),不下载任何内容。rclone 必须在 PATH 中;否则,或远程不提供哈希值时,Xylem 会说明原因,并在通过挂载读取文件之前询问。整个文件夹只在本地磁盘上比较。

在 Google Drive 上:位于两个文件夹中的文件是同一个文件;Docs、表格和幻灯片没有哈希值;他人共享的内容以 `s` 显示,“除一个以外全部标记”不会标记它;同一文件夹中的重名由 `rclone dedupe` 处理;删除会进入 Drive 回收站,Xylem 不会清空它,而是显示命令 `rclone cleanup gdrive:`。

服务提供的哈希值是基于信任接受的,而 MD5 可以被故意伪造。
