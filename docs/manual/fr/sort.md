# Trier

Alt+S trie les fichiers par **N**om (Name), **E**xtension (Ext), **D**ate ou
**T**aille (**S**ize). **O**rdre (Order) inverse l'ordre croissant et
décroissant, et **C**hemin (**P**ath) regroupe d'abord les fichiers par
répertoire dans Branch et Showall (tous deux gardent le menu ouvert pour que
vous puissiez choisir la clé ensuite).

L'ordre actif apparaît dans le titre de la fenêtre de fichiers (`Size↓`) et le
curseur reste sur le même fichier. Chaque fenêtre a son propre ordre ; l'ordre
initial provient de `sort` et `sort_descending` dans la
[configuration](configuration.md), et les nouvelles fenêtres (F8, Log) héritent
de l'ordre courant.
