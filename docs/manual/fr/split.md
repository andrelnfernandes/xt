# Écran partagé

**F8** ouvre une seconde fenêtre, démarrant dans le même répertoire, et F8 à
nouveau revient à une seule. **Tab** passe de l'une à l'autre (sans partage, Tab
fait la même chose qu'Enter). Chaque fenêtre possède sa propre arborescence, son
curseur, son [Filespec](filespec.md) et son [ordre de tri](sort.md) ; utilisez
`L` ([Log](treespec.md)) pour y ouvrir un autre répertoire.

Avec l'écran partagé :

- [Copier et Déplacer](copy-move.md) proposent le répertoire de l'autre fenêtre
  comme destination ;
- [Comparer](compare.md) compare avec l'autre fenêtre ;
- dans le [sélecteur de dossier](picker.md) (F2), Tab bascule sur l'arborescence
  de l'autre fenêtre ;
- les deux fenêtres sont rafraîchies après toute opération.
