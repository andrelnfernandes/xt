# Touches en vigueur

Dans Xylem, cette rubrique liste les touches en vigueur, générées à partir de la
table des raccourcis ; elle inclut donc les modifications apportées dans la
[configuration](configuration.md) (`[keys.any]`, `[keys.tree]`,
`[keys.files]`). Appuyez sur **K** dans l'aide pour l'afficher, ou lancez
`xy --help` pour voir les options de la ligne de commande.

Pour le rôle de chaque touche, voir [la fenêtre d'arborescence](tree.md), [la
fenêtre de fichiers](files.md) et [marquage et opérations groupées](tagging.md).
