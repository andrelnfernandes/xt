# Keys in effect

Inside Xylem, this topic lists the keys in effect, generated from the key map,
so it includes the changes made in the [configuration](configuration.md)
(`[keys.any]`, `[keys.tree]`, `[keys.files]`). Press **K** in the help to see
it, or run `xy --help` for the command line options.

For what each key does, see [the tree window](tree.md), [the file
window](files.md) and [tags and group operations](tagging.md).
