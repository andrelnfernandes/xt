# Aktive Tastenbelegung

Innerhalb von Xylem listet dieses Thema die aktuell gültige Tastenbelegung auf,
direkt aus der internen Tastenzuordnung erzeugt – einschließlich aller
Anpassungen aus der [Konfiguration](configuration.md) (`[keys.any]`,
`[keys.tree]`, `[keys.files]`). Drücken Sie in der Hilfe **K**, um die Liste zu
sehen, oder führen Sie `xy --help` für die Befehlszeilenoptionen aus.

Was die einzelnen Tasten bewirken, erfahren Sie unter [das
Baumfenster](tree.md), [das Dateifenster](files.md) sowie [Markierungen und
Gruppenoperationen](tagging.md).
