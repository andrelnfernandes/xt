# Las teclas activas

Dentro de Xylem, este tema lista las teclas activas, generadas a partir del mapa
de teclado, de modo que incluye los cambios hechos en la
[configuración](configuration.md) (`[keys.any]`, `[keys.tree]`, `[keys.files]`).
Pulsa **K** en la ayuda para verla, o ejecuta `xy --help` para ver las opciones
de la línea de comandos.

Para saber qué hace cada tecla, consulta [la ventana del árbol](tree.md),
[la ventana de archivos](files.md) y
[marcas y operaciones en grupo](tagging.md).
