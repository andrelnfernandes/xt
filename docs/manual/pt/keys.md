# Teclas em vigor

Dentro do Xylem, este tópico lista as teclas em vigor, geradas a partir do mapa
de teclas, incluindo portanto as alterações feitas na
[configuração](configuration.md) (`[keys.any]`, `[keys.tree]`, `[keys.files]`).
Pressione **K** na ajuda para vê-lo, ou execute `xy --help` para ver as opções
de linha de comando.

Para saber o que cada tecla faz, veja [a janela da árvore](tree.md),
[a janela de arquivos](files.md) e
[marcações e operações em grupo](tagging.md).
