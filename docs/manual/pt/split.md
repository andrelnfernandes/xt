# Tela dividida

**F8** abre uma segunda janela, começando no mesmo diretório, e F8 novamente
volta a uma só. **Tab** alterna entre elas (sem a divisão, Tab faz o mesmo que
Enter). Cada janela tem sua própria árvore, cursor, [Filespec](filespec.md) e
[ordem de classificação](sort.md); use `L` ([Log](treespec.md)) para abrir
outro diretório nela.

Com a tela dividida:

- [Copiar e Mover](copy-move.md) sugerem o diretório da outra janela como
  destino;
- [Comparar](compare.md) compara com a outra janela;
- no [seletor de pastas](picker.md) (F2), Tab alterna para a árvore da outra
  janela;
- ambas as janelas são atualizadas após qualquer operação.
