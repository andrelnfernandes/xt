# Split screen

**F8** opens a second window, starting in the same directory, and F8 again goes
back to one. **Tab** switches between them (without the split, Tab does the same
as Enter). Each window has its own tree, cursor, [Filespec](filespec.md) and
[sort order](sort.md); use `L` ([Log](treespec.md)) to open another directory
in it.

With the screen split:

- [Copy and Move](copy-move.md) suggest the other window's directory as the
  destination;
- [Compare](compare.md) compares with the other window;
- in the [folder picker](picker.md) (F2), Tab switches to the other window's
  tree;
- both windows are refreshed after any operation.
